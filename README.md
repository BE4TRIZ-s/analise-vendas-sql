# 📊 Análise Exploratória de Vendas no Varejo (MySQL)

## 📌 Visão Geral do Projeto
Este projeto consiste na criação e análise exploratória de um banco de dados de vendas de uma loja de vestuário. O objetivo é extrair métricas de desempenho de negócios, como faturamento total, ticket médio, análise temporal de vendas e ranking de produtos/categorias mais rentáveis.

---

## 🛠️ Tecnologias e Conceitos Utilizados
- **Database:** MySQL
- **DDL:** `CREATE DATABASE`, `CREATE TABLE`
- **DML:** `INSERT INTO`
- **DQL / Agregações:** `SELECT`, `SUM()`, `AVG()`, `COUNT()`, `ROUND()`, `MONTH()`
- **Agrupamento e Ordenação:** `GROUP BY`, `ORDER BY`

---

## 🔍 Perguntas de Negócio Respondidas

1. **Qual é o faturamento total e o volume de vendas da loja?**
2. **Qual é o ticket médio por transação?**
3. **Qual categoria de produto gera maior receita?**
4. **Qual é a distribuição do faturamento entre os públicos (Feminino vs. Masculino)?**
5. **Como o faturamento e o volume de vendas evoluem mês a mês?**
6. **Quais produtos possuem maior representatividade em receita e em volume vendido?**
